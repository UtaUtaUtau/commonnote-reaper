# commonnote-reaper

ReaScripts for supporting [commonnote](https://github.com/ExpressiveLabs/commonnote) as a cross-application copy paste specification.

# Installation

1. Install [ReaPack](https://reapack.com/).
2. Open REAPER and go to Extensions > ReaPack > Import repositories...
3. Paste this URL: https://github.com/UtaUtaUtau/commonnote-reaper/raw/main/index.xml
4. Go to Extensions > ReaPack > Browse packages...
5. Search for SWS/S&M extensions and install it.
6. Search for commonnote-reaper and install all the packages listed.
7. Restart REAPER.
8. (Optional) Bind a keybind to both actions.
   - Ctrl + Alt + Shift + C/V is free in REAPER's default keybinds.

# Extra

This project includes [json.lua](https://github.com/rxi/json.lua) in its entirety for JSON encoding/decoding.
